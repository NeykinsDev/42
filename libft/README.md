# Libft

## Description
Libft is the first project in the 42 common core. The objective is to reimplement essential standard C library functions (`libc`), along with additional utility functions that will serve as a foundational toolkit projects.

## Project Structures

### 1. Libc Functions (standard Library)
Functions reimplement from `<ctype.h>`, `<string.h>`, `<strings.h>`, and `<stdlib.h>`

* **Character checks:**
* `ft_isalpha` - Test for an alpabetic character
* `ft_isdigit` - Test for a digit.
* `ft_isalnum` - Test for an alphanumeric character.
* `ft_isascii` - Test for a 7-bit ASCII character.
* `ft_isprint` - Test for any printable character.
**Conversion & Case:**
* `ft_toupper` - Convert lowercase letter to uppercase
* `ft_tolower` - Convert uppercase letter to lower
* `ft_atoi` - Convert ASCII to integer
